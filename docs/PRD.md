# 秒薪浮窗 PRD

## 1. 文档信息

- 产品名称：秒薪浮窗（WorkPrice）
- 产品形态：macOS 原生菜单栏与桌面浮窗应用
- 文档版本：V1.0
- 目标系统：macOS 14 及以上
- 数据存储：本机存储，无需账号及网络服务

## 2. 产品背景

用户在工作过程中很难直观感知时间对应的收入，也难以了解当天实际工作时长和下班后的额外工作时间。

秒薪浮窗通过持续展示当天收入、下班倒计时和工作时长，帮助用户实时了解当天的工作与收入状态。

## 3. 产品目标

1. 用户可以手动开始或暂停工作计时。
2. 根据用户配置的秒薪，实时计算当天已挣金额。
3. 清晰展示距离下班时间、已工作时长和无偿打工时长。
4. 以低干扰浮窗常驻桌面，并可从菜单栏快速操作。
5. 应用退出、重启或系统休眠后，计时和金额仍保持准确。

## 4. 目标用户

- 希望实时查看工作收入的职场用户。
- 需要记录实际工作时间及下班后工作时间的用户。
- 希望通过可视化反馈提升工作动力的用户。

## 5. 核心使用流程

### 5.1 首次使用

1. 用户启动应用。
2. 应用在屏幕右下角显示浮窗。
3. 用户进入设置页面。
4. 用户配置秒薪、上班时间、下班时间及下班后计薪规则。
5. 用户保存设置并返回浮窗。

### 5.2 开始工作

1. 用户点击“开始工作”。
2. 状态切换为“工作中”。
3. 应用开始累计工作时长。
4. 应用根据秒薪实时更新当天已挣金额。

### 5.3 暂停休息

1. 用户点击“暂停休息”。
2. 状态切换为“休息中”。
3. 工作时长和金额停止增长。
4. 用户再次开始工作后继续累计。

### 5.4 下班后工作

- 若关闭“下班后继续计薪”，下班后金额停止增长，工作时间计入“无偿打工时长”。
- 若开启“下班后继续计薪”，下班后金额继续增长，“无偿打工时长”保持为 0。

## 6. 功能需求

### 6.1 工作状态

- 支持“工作中”和“休息中”两种状态。
- 默认状态为“休息中”，但若上次退出时仍在工作，应恢复“工作中”。
- 状态由用户手动切换。
- 浮窗和菜单栏均可切换工作状态。
- 工作中使用绿色状态标识，休息中使用灰色状态标识。

### 6.2 今日已挣

- 金额计算公式：

  `今日已挣 = 当天有效计薪秒数 × 对应时段秒薪`

- 内部计算保留完整精度，界面显示两位小数。
- 工作暂停时金额停止增长。
- 修改秒薪后，新秒薪仅对修改后的工作时段生效，不追溯修改历史金额。
- 系统休眠、应用卡顿或重启不应造成金额丢失或重复计算。

### 6.3 距离下班

- 根据配置的下班时间显示倒计时。
- 展示格式为 `HH:mm:ss`。
- 到达下班时间后显示 `00:00:00`。
- 同时显示“今日下班时间已到”提示。
- 支持跨午夜班次，例如 `22:00–06:00`。

### 6.4 秒薪设置

- 用户可输入大于 0 的秒薪。
- 支持小数，例如 `0.0367`。
- 输入框显示单位 `¥/秒`。
- 同时展示换算后的参考时薪。
- 非法值、空值或小于等于 0 的值不得保存。

### 6.5 工作时间设置

- 用户可配置统一的上班时间和下班时间。
- 上班时间和下班时间不得相同。
- 上班时间晚于下班时间时，按跨午夜班次处理。
- 普通班次按自然日归档。
- 跨午夜班次按班次开始日归档。

### 6.6 已工作时长

- 统计当前账目日内全部处于“工作中”的时间。
- 休息时间不计入。
- 展示格式为 `Xh XXm XXs`。
- 跨日期持续工作时自动切分记录。

### 6.7 无偿打工时长

- 仅在关闭“下班后继续计薪”时累计。
- 统计下班时间之后仍处于“工作中”的时长。
- 无偿打工期间金额停止增长，但已工作时长继续增长。
- 持续工作跨过午夜时，在下一班次开始前仍保持无偿状态。

### 6.8 设置生效规则

- 保存设置后立即生效。
- 若保存时处于“工作中”，应用应在保存时刻切分工作记录。
- 已产生的收入使用旧秒薪和旧计薪策略。
- 保存后的工作时间使用新配置。
- 保存失败时保留设置页面，并显示错误信息。

### 6.9 浮窗

- 应用启动后默认显示在主屏幕右下角。
- 浮窗尺寸约为 `340 × 430`。
- 浮窗保持置顶，但不主动抢占其他应用焦点。
- 支持拖动，并记忆上次位置。
- 支持跨 macOS Space 显示。
- 显示器断开或分辨率变化后，浮窗应自动回到可见区域。
- 关闭按钮仅隐藏浮窗，不退出应用。

### 6.10 菜单栏

菜单栏提供以下操作：

- 开始工作或暂停休息。
- 显示浮窗。
- 隐藏浮窗。
- 打开设置。
- 退出应用。

### 6.11 本地持久化

- 保存用户设置、工作记录和当前工作状态。
- 应用重启后恢复未结束的工作记录。
- 数据全部存储在本机。
- 数据库不可用时允许应用以临时模式运行，但必须向用户显示数据无法持久保存的提示。

## 7. 界面信息架构

### 7.1 主浮窗

从上到下包含：

1. 当前状态、日期、设置按钮和隐藏按钮。
2. 今日已挣金额。
3. 距离下班倒计时。
4. 秒薪、已工作时长、无偿打工时长。
5. 开始工作或暂停休息按钮。

### 7.2 设置页面

包含：

1. 秒薪输入框。
2. 折合时薪。
3. 上班时间。
4. 下班时间。
5. 下班后继续计薪开关。
6. 当前计薪规则说明。
7. 保存和取消按钮。

## 8. 视觉要求

- 整体采用深色磨砂玻璃风格。
- 今日金额使用暖黄色作为主视觉。
- 工作中状态使用绿色。
- 倒计时使用高对比度白色和等宽数字。
- 数字每秒刷新时不得出现明显布局跳动。
- 支持 VoiceOver、降低透明度和系统深浅色设置。

## 9. 非功能需求

### 9.1 准确性

- 计时基于真实时间区间计算，不通过 Timer 次数累加。
- 金额使用十进制定点数计算，避免浮点误差。
- 时间计算需正确处理跨午夜和夏令时变化。

### 9.2 性能

- 正常运行时 CPU 和内存占用保持较低。
- 界面每秒刷新一次。
- 历史记录增长不应明显影响浮窗刷新速度。

### 9.3 稳定性

- 应用重启、休眠唤醒及系统时间正常变化后数据保持正确。
- 持久化失败不得静默丢失数据。
- 应用隐藏后可通过菜单栏恢复。

### 9.4 隐私

- 不采集用户身份、工作内容或设备行为。
- 不上传任何数据。
- 不要求网络权限。

## 10. 验收标准

1. 用户可从浮窗和菜单栏切换工作状态。
2. 工作中金额与工作时长每秒更新，休息时停止更新。
3. 下班后按照配置正确处理计薪和无偿时长。
4. 秒薪修改不会改变修改前已产生的金额。
5. 普通班次和跨午夜班次均能正确计算倒计时及账目日期。
6. 应用退出并重新启动后，设置和工作状态可以恢复。
7. 浮窗首次启动位于屏幕右下角，拖动后可记忆位置。
8. 显示器变化后浮窗不会停留在屏幕外。
9. 设置页只显示一个秒薪输入值，输入校验和保存行为正确。
10. Debug 和 Release 构建成功，自动化测试全部通过。

## 11. V1.0 不包含

- 用户账号和云同步。
- 自动识别键鼠活跃状态。
- 节假日、调休和按星期配置班次。
- 历史日报、周报和图表。
- 数据导入、导出和备份。
- 开机自动启动。
- App Store 上架和订阅付费。

## 12. 后续规划

- V1.1：历史工作记录、日报和周报。
- V1.2：CSV 导出及本地备份。
- V1.3：按星期配置班次、节假日与调休。
- V1.4：开机启动、快捷键及浮窗尺寸主题配置。
